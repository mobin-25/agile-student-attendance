

\# Student Attendance Management System (SAMS)



A simple web application prototype for demonstrating Agile development and Git/GitHub workflows.



\## Features

\- Student login interface concept

\- Attendance management

\- Attendance history

\- Attendance reports



\## Technologies

\- HTML

\- Git

\- GitHub

\- GitHub Actions (for CI/CD in a later question)

\## Attendance History



The system will allow students to view their attendance records

by date and subject.
